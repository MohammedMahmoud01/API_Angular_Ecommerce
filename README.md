# ⚙️ E-Commerce Backend API (ASP.NET Core)

A robust **ASP.NET Core Web API** designed as the backend for Angular and Xamarin applications.  
This API handles secure authentication, product management, order processing, and data persistence with SQL Server.

## 🚀 Features
- User authentication & authorization
- Product catalog management (CRUD operations)
- Shopping cart & order processing
- API endpoints consumed by Angular web and Xamarin mobile apps
- Secure, scalable, and maintainable architecture

## 🛠️ Tech Stack
- **Backend:** ASP.NET Core Web API  
- **Database:** SQL Server  
- **Authentication:** ASP.NET Identity + JWT
